# Mood Garden

Final website files for GitHub Pages.

## Files

- `index.html` — page structure and content
- `styles.css` — colours, layout and animations
- `script.js` — buttons and game interactions
- `assets/` — place for future images or diagrams

## Publish

Upload the contents of this folder directly into the root of the public `ai-project` GitHub repository. Then, in GitHub Pages, deploy from the `main` branch and the `/root` folder.
